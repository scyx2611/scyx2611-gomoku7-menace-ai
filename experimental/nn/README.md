# 實驗分支：位子牌＋神經網路（只靠規則）

> 狀態：**可行性試驗中，尚未整合進 main**。需要 PyTorch（`pip install torch`）。

所有版本都只用五子棋規則：網路只看原始棋盤（自己的子、對手的子、全 1 平面），
不知道「線」「子數」「攻守」，訓練對手只有自我對弈（90%）與隨機（10%）。

## 試過的版本

| 檔案 | 做法 | 結果 |
|---|---|---|
| `nncard.py`、`nncard_trial.py` | 網路直接輸出每個位置的牌數，終局後按比例增減（策略梯度＋估值基準） | **失敗**：兩次試驗都在 3～6 萬局時下法完全固定（熵降到 0），攻防測驗回到亂下水準。紀錄：`nn_trial1.log`（學習率 0.001、熵係數 0.01）、`nn_trial2.log`（0.0003、0.05） |
| `nntd.py`、`nntd_trial.py` | 網路只估「下完之後的盤面」勝算 V；牌數 = 10 × e^(10·V) 按比例抽；終局後 TD(λ) 修正 | **有效**：10 萬局時能連五 56.6%、擋四 56.7%、擋活三 46.2%；對隨機版規則型先手 36 勝 36 和（每 100 局）。紀錄：`nntd_trial.log`，權重：`nntd_100k.pt` |
| `nntd_continue.py` | 從第 10 萬局接續訓練到 30 萬局 | **持續進步**：30 萬局時能連五 86.0%、擋四 75.0%、擋活三 64.1%。紀錄：`nntd_continue.log`，權重：`nntd_300k.pt` |

## 30 萬局的結果（單一種子）

| 局數 | 能連五 | 擋四 | 擋活三 |
|---|---|---|---|
| 10 萬 | 56.6% | 56.7% | 46.2% |
| 15 萬 | 67.8% | 56.0% | 59.0% |
| 20 萬 | 77.9% | 65.6% | 63.5% |
| 25 萬 | 77.3% | 68.8% | 46.1% |
| 30 萬 | 86.0% | 75.0% | 64.1% |

凍結評估（勝 / 和）：

| 對手 | AI 先手 | AI 後手 |
|---|---|---|
| 規則型（隨機版，200 局） | 64% / 33% | 65% / 28% |
| 棋形計分規則型（200 局） | 0% / 22% | 0% / 4% |
| Minimax 深度 2（100 局） | 0% / 25% | 0% / 2% |
| 隨機（200 局） | 100% / 0% | 98% / 0% |

比較（攻防測驗：能連五 / 擋四 / 擋活三）：

- 完全亂下：8.5% / 8.9% / 8.3%
- 第四種模式（只靠規則・小區塊）：43.9% / 17.6% / 24.9%（3 種子平均）
- 第二次修正（程式先算好攻守）：65.5% / 75.3% / 84.4%（3 種子平均）

注意：只有一個種子，且「擋活三」在 25 萬局時曾下降，正式結論需要多個種子。
