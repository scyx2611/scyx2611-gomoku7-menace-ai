# 實驗分支：位子牌＋神經網路（只靠規則）

> 狀態：**可行性試驗中，尚未整合進 main**。需要 PyTorch（`pip install torch`）。

所有版本都只用五子棋規則：網路只看原始棋盤（自己的子、對手的子、全 1 平面），
不知道「線」「子數」「攻守」，訓練對手只有自我對弈（90%）與隨機（10%）。

## 試過的版本

| 檔案 | 做法 | 結果 |
|---|---|---|
| `nncard.py`、`nncard_trial.py` | 網路直接輸出每個位置的牌數，終局後按比例增減（策略梯度＋估值基準） | **失敗**：兩次試驗都在 3～6 萬局時下法完全固定（熵降到 0），攻防測驗回到亂下水準。紀錄：`nn_trial1.log`（學習率 0.001、熵係數 0.01）、`nn_trial2.log`（0.0003、0.05） |
| `nntd.py`、`nntd_trial.py` | 網路只估「下完之後的盤面」勝算 V；牌數 = 10 × e^(10·V) 按比例抽；終局後 TD(λ) 修正 | **有效**：10 萬局時能連五 56.6%、擋四 56.7%、擋活三 46.2%；對隨機版規則型先手 36 勝 36 和（每 100 局）。紀錄：`nntd_trial.log`，權重：`nntd_100k.pt` |
| `nntd_continue.py` | 從第 10 萬局接續訓練到 30 萬局 | 進行中，`nntd_continue.log` 為推送時的快照 |

完全亂下時，攻防測驗三類題目的機率約 8.5%；第四種模式（3×3 等小區塊牌）30 萬局約 45% / 20% / 20%。

## 重現

python experimental/nn/nntd_trial.py 100000
