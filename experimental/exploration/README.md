# 實驗分支：探索性試驗腳本與紀錄

> 狀態：**只供查證，不是正式實驗**。正式實驗設定在 `configs/`，結果在 `data/`。

檢討報告（`docs/檢討報告.md`）提到的探索性試跑，腳本都在這裡。多數是單一種子、較少局數。

| 檔案 | 用途 | 對應檢討報告 |
|---|---|---|
| `round1_grid.py` | 修正前版本的獎懲參數組合（對確定性規則型，6000 局） | 第 12 節第 1 點 |
| `round1_proto.py` | 第一次修正（棋形位子牌）的原型 | 第 12 節第 1 點 |
| `round1_surv.py` | 存活獎勵與種子差異的試跑 | 第 12 節第 2 點 |
| `round1_stress.py` | Rapfi 串接的壓力測試（多程序並行、可重現性） | 第 12 節第 3 點 |
| `round1_probe.py` | 初期對各對手的速度與勝率探測 | — |
| `probe_dumb.py` | 「連五、擋四、擋活三」三個具體局面的機率 | 第 8 節 |
| `v2grid.py` | 你同意的三項改進（混合對手、關鍵一手、牌數上限） | 第 9.1 節 |
| `v3grid.py`、`v3grid2.py` | 視窗計數棋形的試跑（第一版的評估數字因腳本錯誤無效，`v3grid2.py` 為改正後） | 第 9.1 節、第 12 節第 5 點 |
| `pg.py` | 按比例增減（策略梯度）的第一次驗證 | 第 9.1 節 |
| `rawcard.py`、`rawcard_trial.py` | 只靠規則第 1、2 輪：周圍格子原始內容（單格、雙格）＋策略梯度，學不會防守 | 第 10.2 節 |
| `tdcard.py`、`tdcard_trial.py` | 只靠規則第 3 輪：下完後盤面估值＋小區塊牌，成為第四種模式 | 第 10.3 節、第 12 節第 6 點 |
| `logs/` | 只靠規則各輪試驗的輸出 | |

腳本開頭會自動把專案根目錄加入 import 路徑，可以在任何目錄執行，例如：

```bash
python experimental/exploration/tdcard_trial.py
```
